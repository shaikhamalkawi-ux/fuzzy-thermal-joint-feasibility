# Reproducibility and claim boundary

This repository is a public **source/data/certificate artifact** for the 99FUZZYC research project. Its scientific results are specific to the declared synthetic two- and three-node conservative thermal networks. The uploaded 15-row historical NIST conductivity table is a source transcription for descriptive sensitivity only, not independent validation of the network.

The conference manuscript and editable LaTeX are deliberately *not* included pending author and venue rules; public code availability is not publication or acceptance of the paper. No open-source license or software DOI has yet been approved.

Run `python -m pip install -r requirements.txt && python run_verify.py` from a fresh checkout. The verifier checks 42 original source hashes and byte reproduces 19 numerical/certificate outputs under the declared environment. These are exact model and archival checks, not empirical validation.

This repository is not an official endorsement by NIST, ICMPC, the publisher, or any institution.
