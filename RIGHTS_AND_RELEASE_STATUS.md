# Public release boundaries

This repository is publicly accessible at https://github.com/shaikhamalkawi-ux/fuzzy-thermal-joint-feasibility with the connected account owner's authorization. It includes original scripts, exact generated artifacts, numeric transcription of a cited NIST historical table, and author-produced figures. The manuscript PDF and editable TeX are held outside the public-code bundle pending coauthor and venue policy checks. It does **not** contain publisher PDFs, external paywalled full texts, third-party conference templates, personal communications, account secrets, or historical internal project chats.

**Important:** Public repository access and an open-source license are separate. No MIT/Apache-2.0/CC-BY license is assigned because permission from the actual authors and rightsholders is not verified. The account owner should confirm software contributor rights before issuing a license. If the conference uses anonymous review or has preprint restrictions, the author-controlled working manuscript PDF and any identifying metadata should not be posted publicly until publication policies are confirmed.

No actual physical manufacturing experiment is claimed. The NIST source observations are published historical values, not network measurements or a calibration sample.
