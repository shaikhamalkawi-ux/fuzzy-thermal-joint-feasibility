# Fuzzy thermal networks: exact joint feasibility and attained repairs

Public research code and machine-readable exact certificates for synthetic two- and three-node conservative thermal-network examples. The full reproducibility tree is being published in this repository.

This is **not** experimentally validated materials-processing performance or a published conference article.

The scientific R6 baseline is locked; the working editorial manuscript is not submitted. No open-source license or software DOI is claimed.
